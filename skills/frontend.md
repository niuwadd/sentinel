# Frontend Design & UI

当以下情况发生时，加载 `frontend-design` 技能：

- 创建新的 UI 组件、页面、控件面板
- 要求审美决策（颜色、间距、字体、排版）
- 设计 3D 场景中的 UI 覆盖层（标注、标签、面板）
- 编写任何 `client/src/components/Panel/` 下的组件

需要"看起来很贵"的视觉效果时额外加载 `high-end-visual-design`。

需要配色/字体/布局参考时加载 `ui-ux-pro-max`。

始终参考 `client/DESIGN.md` 中的 Material You 暖色调 Design Token，设计风格必须与现有组件（FrostedGlass、GlobalStats、RoomStrip）保持一致。
